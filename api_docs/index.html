Flutter quick start

DART

Connect once, listen for response type values, and send JSON-encoded maps.

import 'dart:convert';
import 'package:web_socket_channel/web_socket_channel.dart';

final channel = WebSocketChannel.connect(
  Uri.parse('ws://localhost:8080'),
);

channel.stream.listen((frame) {
  final message = jsonDecode(frame as String)
      as Map<String, dynamic>;
  if (message['type'] == 'otp-sent') {
    print(message['mockCode']); // mock mode only
  } else if (message['type'] == 'results') {
    final ads = message['data'] as List<dynamic>;
    print('Received ${ads.length} ads');
  }
});

channel.sink.add(jsonEncode({
  'action': 'request_otp',
  'phone': '09123456789',
}));

For Android Emulator, use 10.0.2.2 instead of localhost. Add the web_socket_channel package to your Flutter app.

This service exposes WebSocket actions rather than REST endpoints. Mock OTP codes are returned only when mock mode is enabled.
